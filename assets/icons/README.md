# Icon sources

The SVG logo assets in this directory were downloaded from [Skill Icons](https://github.com/tandpfun/skill-icons) using its public icon endpoint. The upstream MIT license is included in `LICENSE`. Brand marks belong to their respective owners.

`tools/render_profile_ui.py` embeds these vectors into local, self-contained toolkit cards. Its React Flow, WebGL2, Ollama, RAG and WebAssembly symbols are simple illustrative glyphs, not official logos.
