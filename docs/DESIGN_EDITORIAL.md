# Editorial design review

Scope: `README.md` and this report only. Asset work belongs to the other designers.

## Critique

- Galaxy's dense paragraph makes the reader extract the product, engineering contribution, and data caveat from one block. Those are three different jobs.
- The supplied screenshot is a wall of competing labels and grid lines. Enlarging it makes the blur louder; copy cannot repair the underlying capture.
- Burying the live demo below that image delays the strongest evidence. Private source links then offer dead ends instead of useful actions.
- GoodFlow's feature list needs breathing room. Its illustration is useful orientation, but must remain clearly identified as an illustration.
- The night hero already provides atmosphere. More badges, decorative headings, or a second visual theme would weaken the purple portfolio identity.

## Implemented

- Preserved the hero markup exactly, including the animation and reduced-motion still.
- Kept Galaxy first and retained the specific introduction, degree, availability, portfolio, and LinkedIn links.
- Split Galaxy's interaction summary from its C++ / WebAssembly / WebGL2 implementation and catalogue/procedural distinction.
- Moved the live Galaxy action above its image; removed the private Galaxy repository and catalogue-file links.
- Retained GoodFlow's repository action after the user's verification that it is public; separated its implementation stack from the feature summary.
- Set both project images to `width="800"`. The inspected Galaxy JPEG is 1199 × 450, and GoodFlow's SVG is 800 × 160: neither needs enlargement. GitHub's image styling handles narrower containers. The main designer may replace the Galaxy asset or adjust its path.
- Used ordinary headings, paragraphs, links, image alternatives, and a readable illustration caption. Kept all six meaningful technology icons with visible text labels.

## Verification and limits

- Compared the hero block against the baseline; checked project order, required public links, removal of both Galaxy source destinations, and local image references.
- Inspected the supplied screenshot, current Galaxy JPEG, hero still, and GoodFlow SVG source. No new capability, metric, experience, or project was introduced.
- This editorial pass does not claim a fresh browser render, live-link check, or improved Galaxy capture. The user supplied the repository visibility verification; the main designer owns image replacement and final visual review.
- No assets edited; no commit or push.
